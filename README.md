# C++ Game Engine Master Plan — 140 Days (v3.5)

Portfolio-first roadmap from Unity/C# programmer to junior **C++ / engine / tools** roles.

## Layout

| Path      | What lives here |
|-----------|-----------------|
| `plan/`   | The single master plan (Markdown + Word) — `cpp-engine-master-plan-v3.5` |
| `tracker/`| `day-tracker.md` — your daily scorecard (tick a box when a day's `Done` line is true) |
| `solutions/` | Brand-new Day N builds, starting Day 1 — one folder per day |
| `docs/`   | Devlog, interview bank, pitch refresh (added through the phases) |

## Ritual (30 seconds, twice a day)

1. **Morning:** open `tracker/day-tracker.md`, set `You are on Day: N`.
2. **Evening:** when the day's `Done` line is true, tick the box and commit:
   `git add -A` then `git commit -m "Day N: <what you built>"`, then `git push`.
3. Milestone days earn git tags: `cpp-core` (21), `math-v0.1` (28), `graphics-v1` (56),
   `engine-v1` (91), `voxel-freeze` (103), `engine-portfolio` / `cpp-mastery-lite` (140).

The plan's full rules live in `plan/cpp-engine-master-plan-v3.5.md` (including the golden rule:
*extend, don't skip*).
